what is RTGS Transactions Analysis?
-------------------------------------
This project analyzes RTGS (Real Time Gross Settlement) transaction data of Indian banks. RTGS is used for large-value, real-time fund transfers.The dataset contains bank-wise details like month, year, inward/outward volume and amount. Using Python (Pandas, Seaborn, Plotly), we performed Exploratory Data Analysis (EDA).We used Bar plots to find top banks, Line plots to find monthly trends and seasonality, Scatter plots to study the relationship between inward and outward transactions, and Bubble charts to visualize 4 variables together.The analysis helps to understand fund flow patterns, bank performance, and growth of digital transactions over years.
Tools Used: Python, Pandas, Matplotlib, Seaborn, Plotly.


Project Objective:
----------------------------------
The main objective of this project is to analyze the RTGS (Real Time Gross Settlement) transaction data of various Indian banks to understand the flow of funds.
To analyze Bank-wise performance in terms of Inward and Outward Volume and Amount.
To identify monthly and yearly trends and seasonality in RTGS transactions.
To study the relationship between transaction volume and transaction amount.
To compare Inward vs Outward transactions to find if the banking system is balanced.
To use visualizations like Bar plots, Line plots, Scatter plots and Interactive Bubble charts for better insights.
